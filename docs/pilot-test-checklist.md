# What to try yourself (about an hour, synthetic data)

Use two browser windows (or a phone plus a laptop), signed in as two different people, because the system won't let
one person approve their own work. Make up every name and number.

**Set up (admin + you)**
- [ ] Accept your invitation, set up two-factor, save the recovery codes.
- [ ] Invite a test agent and a test admin (plus-addresses of your email).
- [ ] Admin → Broker of record & accounts: have the admin record your designation; add the trust and operating accounts.
- [ ] Admin → Commission plans: admin proposes a plan for the test agent; you approve it.

**A sale, start to finish (as the agent, then you)**
- [ ] Deals → New deal: a listing, $899,000, deposit $50,000 held by our brokerage. Try submitting it empty first: are the messages clear?
- [ ] Upload a listing agreement (any PDF) and the seller's FINTRAC ID record. Approve one, send one back. Does the agent see why?
- [ ] Trust tab: record the $50,000 deposit.
- [ ] Bank & reconciliation: import a one-line CSV for that deposit; have someone else verify it; prepare and sign the month.
- [ ] Overview: add a condition, mark it fulfilled, mark firm, record the closing. Add the seller's lawyer.
- [ ] Trade record: prepare it, correct one item, sign as the agent, then as broker of record. Print it.
- [ ] Closing & CDA: check the statement, open the lawyer copy, finalize. Void it and issue the correction.
- [ ] Bank → Available funds: enter obligations (needs the manual procedure policy on), have someone else attest.
- [ ] Record commission received (try part first, then the rest); import and verify the bank file; approve the payout;
      have the admin record it paid.

**From your phone**
- [ ] Sign in, open the deal, check the trust tab, approve something.

**What to judge**
- Faster or slower than Lone Wolf for the same step?
- Anything you had to guess? Any message that didn't tell you what to do next?
- Anything you'd expect to see that isn't there?

Note it as you go; that list decides what (if anything) gets built next.
